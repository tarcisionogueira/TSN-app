## 2. ZUK — matrícula login-gated (captura on-demand) — `api/_zuk-auth.js`

O Portal Zuk deixa o **edital público** (link direto no HTML), mas **tranca a matrícula atrás de login**: no HTML anônimo o card da matrícula vem com `href=""` e só abre o modal de login; o servidor só injeta a **URL assinada (CloudFront)** do PDF quando a sessão está autenticada.

- `capturarDocsZukLogado()` faz o login Laravel padrão **sob demanda** — só quando alguém **ANALISA** um lote do Zuk (nada em massa): GET no lote (pega `_token` CSRF + cookies) → POST `/login` → GET autenticado → vasculha o HTML (reaproveita `_doc-scan`) → devolve a matrícula.
- Ligado em `api/gerar-documental.js` (≈linha 476): se `fonte` é Zuk e ainda não há matrícula, loga on-demand e adiciona a URL assinada aos anexos, com **prioridade** (`prioTipo.matricula = 0`) para não ser empurrada para fora do cap por vários links de edital.
- **Credenciais:** `ZUK_EMAIL` / `ZUK_SENHA` (env do Vercel). ⚠️ **Novas variáveis** — conferir se estão setadas em Production.
- O href assinado é extraído direto do card `property-documents-item` (commit `760896f`, depois de rodadas de debug logando os `<a>` dos cards).

## 3. Captura de documentos ligada nos leiloeiros (`enriquecerDocumentosLote`)

Para os leiloeiros com **página de detalhe server-rendered**, o scraper roda `enriquecerDocumentosLote(browser, imoveis, { cap })` **antes de salvar**: abre a página do lote e captura edital/matrícula/laudo (rede + varredura de `<a href*.pdf>`), guardando em Storage + `imovel_anexos`. Isso alimenta tanto os relatórios das IAs quanto o **mapa exato** (§4).

Ligado nesta leva em: **Superbid** (cap 150), **Sold** (120), **PortalZuk** (120), **Sodré** (120), **Frazão**, **Pestana**, **Grupo Lance**.
- **Pestana:** monta `anexos` do JSON — edital do **leilão** + matrícula/laudo **do lote/bem**. Matrícula só de doc por-lote (nunca do leilão), senão o mesmo arquivo gruda em todos os lotes.

## 4. Análise jurídica — confiabilidade

- **Exigir matrícula E edital lidos antes do laudo** (`84ba0a7`): trava dupla (pré e pós-geração). Se a IA não confirmou leitura dos dois, não entrega laudo inconclusivo — pede só o(s) que falta(m), enfileira a captura e **estorna a cota**. Mata o laudo "não identifiquei o CPF".
- **Contradição "matrícula lida vs. certidão atualizada"** (`4a45ba2`): quando o edital vem num PDF único (edital + auto + matrícula transcrita), a IA extraía todos os ônus/cadeia mas ainda escrevia "não foi possível ler a matrícula". Regra de coerência no prompt: se extraiu R-/Av-, ônus e cadeia → **leu** a matrícula (`documentosAnalisados.matricula=true`); a certidão atualizada no CRI vira **diligência de pré-lance** ("a confirmar", informativo/alerta), nunca falha de leitura. (Caso Santana de Parnaíba.)
- **Mapa exato via endereço da matrícula** (`64fdf50`): a IA já lê a matrícula p/ o laudo; agora extrai também o endereço (logradouro+número+bairro+CEP) e, best-effort no deadline, grava e geocodifica para nível **`endereço`** (pino exato). Endereço exato só existe na matrícula.
- **Pré-checagem de documentos no botão Gerar** (`d211cb6`/`e22d544`): UX que checa os docs antes de disparar.

## 5. Auditoria automática — endurecimento de segurança (`e9c1dda`, `776dd8b`)

Correções dos achados `tipo=auto` da `auditoria_sistema` (cron diário) + advisors Supabase:

- **IDOR no cancelamento de assinatura** (grave): `mp.js` (`cancelar_assinatura`) usava o `email` do body → dava para cancelar assinatura de terceiro. Passa a filtrar **sempre** pelo `external_reference` do usuário autenticado (`${userId}|plano`). Mesma classe em `garantia-cancelar` (cancelava homônimo por e-mail) → usa `perfis.mp_id`.
- **CPF sem dígito verificador**: novo `validarCPF()` em `api/_cpf.js` (algoritmo DV + rejeita dígitos iguais), aplicado em `cpf-set` e `criar-conta-checkout` — barra CPFs fictícios.
- **XSS em e-mail**: novo `escapeHtml()` em `api/_sanitize.js`, aplicado em `enviar-alertas-cron` e `financiamento-alertas-cron` (nome/título/cidade/`imovel_nome`).
- **Prompt injection em `gerar-contrato`**: `arquivos[].conteudo` passa a ser tratado como dado, não instrução.
- **`search_path` mutável** (advisor WARN 0011): `20260709_fix_search_path_sanitiza_valores.sql` → `alter function sanitiza_imovel_valores() set search_path = ''`. **Já aplicada.**
- **IA de indicadores pulava dia**: cron `diagnostico-ia` respeitava cache de 20h (snapshot ~36h velho). `vercel.json` passou a chamar `/api/diagnostico-ia?forcar=1` → regenera todo dia.

## Regras operacionais (lembrete)
- Deploy: `npm run build` → commit em PT → push em `main` (fast-forward do branch da sessão) → Vercel automático.
- Migrações: arquivo em `supabase/migrations/` **e** aplicar no Supabase (SQL Editor ou MCP `apply_migration`).
- Scrapers rodam no **GitHub Actions** (egress liberado; Bright Data devolve 200 vazio nos PDFs com sessão). Filtrar fontes com env `SCRAPER_FONTES`.
- Núcleo jurídico é **Claude-only** por decisão (assertividade); Gemini só no chat de dúvidas.
- Prioridade do dono: **qualidade das funções entregues > segurança de dados/fluxos/pagamentos > economia**. Correções sempre **gerais** (raiz), não lote a lote.
