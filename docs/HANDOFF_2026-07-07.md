Cliente é de quem vendeu pelo link; compra direta = empresa/admin.
- **Wizard de promoção** (Admin PromoTab, 5 passos): produto/curso/ebook → validade do link → desconto 0-100% + validade do desconto → perguntas SDR (expande) → revisar. Aba "Comercial" substituiu "SDR/Leads" (monitora todos os clientes pagantes e não pagantes; admin atribui cliente a consultor).
- **Captura de lead + conta automática** (`api/promo-capturar.js`): cria conta (explorador), atribui ao consultor criador do link ou ao afiliado do `?ref`; conta direta sem link → admin/empresa.
