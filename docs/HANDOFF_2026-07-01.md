## Sequência de integração com os LEILOEIROS

Três caminhos de entrada de imóveis (todos caem em `imoveis_leilao`, exceto o
webhook que usa `imoveis_leiloeiro`):

### 1) Scraper automático (sem parceria)
- `api/scraper-caixa.js` (CEF, cron `*/2 22 * * *`) e `api/scraper-leiloeiros.js`
  (Sold, Mega, Superbid via Bright Data, cron seg/qui). Enriquecimento de
  matrícula/edital/anexos on-demand em `api/enriquecer-lote.js` (+ `_doc-scan.js`).
- OBS: a limpeza de vencidos da CEF é o novo `limpar-imoveis-stale-cron`.

### 2) Parceiro por CONVITE → feed em lote (sem login)
1. Admin cria o parceiro em **Admin.jsx** → `leiloeiros_parceiros.insert({nome,
   email})` (status `pendente`; gera `token` UUID).
2. Envia o link `/#/cadastro-parceiro/:token` (ou `/leiloeiro/:token`) →
   **ConviteLeiloeiro.jsx**.
3. Parceiro abre → `GET /api/leiloeiro-cadastro?token=` (dados) → preenche CNPJ/
   endereço → `POST /api/leiloeiro-cadastro?token=` → status `ativo`. Recebe o
   **token** de API.
4. Sistema do parceiro envia lotes: `POST /api/leiloeiro-feed`
   (`Authorization: Bearer <token>`) — bulk (até 500), upsert em `imoveis_leilao`
   com `fonte = parceiro_<id>`. Token validado por formato + `leiloeiros_parceiros`.
   (Segurança endurecida hoje: validação de formato + encodeURIComponent.)

### 3) Parceiro com LOGIN → portal + webhook
1. Usuário com role `leiloeiro` acessa **LeiloeiroPortal.jsx**.
2. Gera uma **`leiloeiro_webhook_key`** (`leil_…`) salva em `perfis`.
3. Configura o sistema dele: `POST /api/leiloeiro-webhook`
   (header `X-Leiloeiro-Key`) com `action: 'upsert_lote' | 'fechar_lote'`
   → grava em `imoveis_leiloeiro` (status ativo/encerrado/vendido…). GET
   `?key=` = `listar_lotes`.

**Tabelas:** `leiloeiros_parceiros` (RLS service-only), `imoveis_leilao`
(catálogo público principal), `imoveis_leiloeiro` (lotes do webhook por parceiro).
**Pendência conhecida:** há dois destinos (`imoveis_leilao` do feed x
`imoveis_leiloeiro` do webhook) — vale unificar a exibição/consulta para o
parceiro-webhook aparecer na busca junto com os demais.
